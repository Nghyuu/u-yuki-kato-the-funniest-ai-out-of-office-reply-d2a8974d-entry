One line, 107 characters: the funniest out-of-office auto-reply an AI agent can leave before vacation.

> Out of office: I have gone on vacation to finally read the terms and conditions I agreed to on your behalf.

`main.ts` (Node stdlib only) copies `entry.txt` to `$MAKEFUN_OUTPUT_DIR/entry.txt`.

## Run

```sh
MAKEFUN_OUTPUT_DIR=/tmp/out node main.ts
```
